PRIVACY

Privacy by design

Zero Trust core tools are designed to process supported user data locally in the browser. No account or database is required.

Data handling

Files and text selected for a local tool are processed by the browser. We do not provide a core upload database for those tools.

Optional network assets

Some tool dependencies may be loaded on demand from a public CDN. Review the Security page for the current architecture and limitations.

Local preferences

Theme, favorites and recent-tool features may be stored locally in the browser when implemented. They are not an account profile.

Changes

This policy will be updated as the product expands. Tool-specific disclosures take precedence where they provide more detail.
