SECURITY

Security transparency

Zero Trust is designed around local-first processing. Core tools use browser APIs and process supported inputs on the device.

What local means

A local tool reads the selected input inside the browser and creates the result without an application server receiving the input.

Network dependencies

Some heavy optional libraries may be loaded from a public CDN when a tool is opened. Loading a library is not the same as uploading the user's file, but users should understand that the page has a network dependency until the required assets are cached.

Encryption

Web Crypto based encryption uses standard browser primitives. Password recovery is intentionally unavailable. Users should independently verify important encrypted data before relying on it.

Limitations

No browser utility can protect a compromised device. Local processing also does not automatically prove that every browser extension or network layer is trustworthy. Zero Trust avoids unnecessary collection and documents its processing model.
